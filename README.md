# Étude PTG – formulaire

Page du formulaire de recueil de l'étude rétrospective sur les prothèses totales de genou posées entre 2018 et 2023 (Service de Chirurgie Orthopédique et Traumatologique, EHS Benaknoun).

Ce dépôt ne contient que la page : aucune donnée de patient. Les fiches sont enregistrées dans un Google Sheets privé, accessible au seul responsable de l'étude. Aucune donnée identifiante du patient n'est saisie (N° de dossier seulement), et chaque fiche ne peut être rouverte que depuis le téléphone qui l'a créée.
